# Лабораторні 3–5 · Лисенко Лука Сергійович · ТР-61МП · 3Б

Три готові PDF знаходяться у `lab3-.../report`, `lab4-.../report`, `lab5-.../report`. Код, raw evidence та скріншоти — поруч. [Повний репозиторій](https://github.com/Lukadjent/kafka-energy-lysenko).

У цьому ZIP є всі власні джерела ЛР3–5, спільні утиліти та мінімальні bootstrap-файли попередніх лабораторних. Runtime binaries, CSV/SSTables, паролі/токени, матеріали викладача та відео виключені. Підготовка portable dependencies і команди запуску наведені в `lab-support/README.md`. Це Windows x64/Python3.12 стенд; усі сервери — loopback.

`MANIFEST.sha256` фіксує точні байти кожного файла в архіві. Перевірка результатів: `python lab-support/validate.py` виводить підсумок у консоль. Відтворення вимірювань потребує завантаження офіційних дистрибутивів і запуску серверів за README. Збережені результати можна перевірити без запуску серверів.

Дані синтетичні. ЛР3: три Cassandra JVM на одному фізичному ПК; 1 296 000 рядків у кожній з3 схем. ЛР4: реальні Java Streams/RocksDB, 30/10-хвилинні вікна з прискореним replay; Saga — симулятор. ЛР5: production durations2h/10m перевірені promtool у віртуальному часі, окремий живий тест15s.
